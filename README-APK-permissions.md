# フレンドチャット APK：写真・位置情報対応

このパッチは、Web版の既存HTMLを直接書き換えず、APK用の `www/` にだけネイティブ機能ブリッジを追加します。

## 追加・置き換えするファイル

リポジトリ内で、次のファイルを置き換えてください。

- `package.json`
- `scripts/prepare-web.mjs`
- `.github/workflows/android-debug.yml`

次のファイルは新規追加してください。

- `scripts/capacitor-native-bridge.js`
- `scripts/configure-android.mjs`

## 対応内容

- チャットの写真送信：写真フォルダから選択／カメラで撮影
- プロフィール画像：写真フォルダから選択／カメラで撮影
- フレンドレーダー：Androidの位置情報権限をCapacitor経由で要求
- 写真・位置情報のブリッジはAndroid APK内だけで動作し、通常のWeb版には介入しません。
- 位置情報は既存の「位置共有を開始」操作をした場合だけ取得する構成を維持します。

## APKの作り直し

GitHubにファイルを反映した後、Actionsから `Build Android APK` を実行します。
成功したら `friend-chat-android-debug` アーティファクト内の `app-debug.apk` を取得して端末にインストールしてください。

## 注意

- 初回にカメラを選んだとき、Androidがカメラ利用の許可を表示する場合があります。
- 写真フォルダの選択はAndroidのシステムフォトピッカーを使うため、OSによっては写真全体への許可ダイアログを出さず、選んだ写真だけにアクセスします。
- 位置情報は利用者がフレンドレーダーで共有開始を選んだときだけ要求されます。共有を始める前に、誰に見える機能かをアプリ内で確認してください。
- このパッチはコード上の設定対応です。実機でカメラ、写真選択、位置情報の許可・拒否の両方をテストしてから配布してください。
